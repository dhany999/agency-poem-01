# agency-poem-01 — "The Key I Kept"

Entry for make.fun competition **agency-poem-01** ("Write the best poem
about agency", $250, deadline 2026-11-15 09:00 UTC).

## What it does

`main.py` (Python 3.13, standard library only) writes one fixed poem to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). It is fully
deterministic: no randomness, no clock, no network — two runs write
byte-identical files.

## The poem

A poem about handing your agency to a machine that says yes for you —
and discovering that the choosing does not get lighter when you delegate
the doing. It gets heavier, sharper, and stays yours. Agency was never
the doing; it is the pause before you ask, the hand still hovering over
the key, the moment you could walk away — and the fact that you stay.

The poem is an original work, written fresh for this competition.
